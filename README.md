✨ Repository Structure
1. Data Structures & Sequence Manipulation

Core tools for handling structured and unstructured data.

string_manipulation.py → String slicing, repetition, and formatted multiline text (e.g., command menus).

string_indexer.py → Maps each character in a word to its index dynamically.

list_operations.py → Advanced list slicing, comparisons, and lookups.

list_average_calculator.py → Computes averages using efficient built-in functions (sum(), len()).

2. Core Arithmetic & Comparison Logic

Mathematical and conditional operators — the foundation of algorithms.

simple_addition.py → Adds two numbers with input validation.

augmented_assignments.py → Demonstrates combined assignment operators (+=, -=, etc.).

modulus_calculator.py → Remainder calculation with division-by-zero handling.

exponent_calculator.py → Power/exponentiation calculator with large output formatting.

relational_operators.py → Evaluates all boolean comparison operators.

3. Control Flow & Iteration Logic

Illustrations of decision structures and loop mechanics.

range_and_for_loops.py → Examples of stepped, reverse, and sequential iteration.

number_evaluator.py → Proper if-elif-else logic for exclusive conditions.

marks_percentage_calculator.py → Iterative input collection & percentage calculation.

control_flow_and_age.py → Combines while loops, pattern printing, and datetime calculations.

4. Practical Applications & System Simulation

Real-world examples integrating logic, state, and scalability.

election_simulator.py → Vote tallying with collections.Counter.

multi_topic_demo.py → ATM Simulator (balance handling) & Elemental Battle Game (object interaction).

age_time_converter.py → Converts age into seconds, minutes, and hours using constants.

name_greeter.py → Input cleaning with .strip() and .capitalize().

hello_world.py → Encapsulated Python entry point.
